Third-party tools retain their own licenses.

## Project assets

| Files | Provenance |
| --- | --- |
| `structures/*.octa` | Procedural structures authored in `gen/scenes/` and `gen/kit/`, generated by the Go toolkit; `neighbors.octa` is a small format fixture |
| `assets/*.svg`, `assets/ui/icons/*.svg` | Vector icons stored as editable SVG source in this repository |
| `assets/ui/splash.png`, `assets/ui/button-chrome.png` | AI-generated using Sunburst on fal.ai; prompts and generation settings are retained in `assets/ui/prompts/` and JSON sidecars |
| `assets/ui/button-chrome-runtime.png` | Resized derivative of `button-chrome.png` for the nine-slice button skin |
| `.agents/skills/sunburst-images/` | Optional Ruby artwork tooling and prompt reference material, authored by the maintainer (makevoid) |

The artwork is included in the checkout; running Octa does not contact the image
service. Sidecar image paths are repository-relative. Model output is not guaranteed
to be reproducible from the same prompt. The maintainer confirmed on 2026-10-26 that
they hold redistribution rights for the AI-generated UI artwork and authored the
`.agents/skills/sunburst-images/` tooling; both are released under the root license.

## Runtime and development tools

- **Godot Engine:** MIT-licensed engine, with its own bundled third-party components.
  No engine binary is stored in this repository. When distributing exported apps,
  include the notices for the exact engine/export template used, following
  [Godot's distribution guidance](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html).
- **Go:** the generator imports only the Go standard library. There are no external
  Go modules to vendor or install.
- **Fonts:** the UI requests system fonts with Godot fallback; this repo bundles
  no separate font files. Do not copy a local system font into a release without
  checking its redistribution terms.
- **Ruby and Excon:** used only by the optional artwork tool; installed separately.
- **FFmpeg:** optional external executable for showcase video generation; not
  included in the repository or required for PNG previews.

For new assets, record the author/source, license, modifications, and any required
attribution here. Preserve upstream license files if third-party code is vendored.
